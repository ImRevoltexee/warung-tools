API buat Developer

Semua endpoint bebas dipakai, balikin JSON, gak perlu API key.

  • GET /api/anime?q=naruto&limit=10 — cari anime
  • GET /api/anime?id=20 — detail satu anime
  • GET /api/gempa — gempa terbaru BMKG
  • GET /api/cuaca?kota=Jakarta — cuaca + prakiraan
  • GET /api/sholat?kota=Jakarta — jadwal sholat hari ini
  • GET /api/sholat?kota=Jakarta&tanggal=2026-09-20 — jadwal tanggal tertentu
Data gempa dan sholat diambil dari sumber publik resmi (BMKG, myQuran). Anime dari Jikan/MyAnimeList. Gue cuma nyalurin plus cache biar cepat — bukan host video atau konten bajakan.
