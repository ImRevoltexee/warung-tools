Base64 Encode / Decode

Aman buat teks unicode dan emoji. Semua proses lokal — tidak ada data yang dikirim ke server.

Pakai tombol "Encode ke Base64" kalau input lu teks biasa. Kalau lu punya string Base64 (biasanya berakhiran = dan cuma berisi huruf/angka/+/ ), pakai tombol Decode.

Berguna buat bikin data URI gambar di CSS, atau nempel file kecil langsung di source code. Jangan pakai buat file gede — bakal lambat.
